# Vídeo de abertura — Rota da Justiça

Coloque o vídeo cinematográfico final nesta pasta com o nome exato:

`rota-da-justica-intro.mp4`

Caminho consumido pelo jogo:

`/videos/rota-da-justica-intro.mp4`

Recomendado:
- MP4 (H.264)
- 1920x1080
- 16:9
- 10 segundos
- sem texto ou logotipos gravados no vídeo
- compressão web para carregamento rápido

A tela usa `autoplay`, `muted`, `loop` e `playsInline`. O botão ENTRAR aparece após 5 segundos. Caso o arquivo não exista ou falhe, o jogo exibe um fallback visual e continua permitindo a entrada normalmente.

Para forçar a intro novamente durante testes na mesma sessão, abra a aplicação com `?intro=1`.
