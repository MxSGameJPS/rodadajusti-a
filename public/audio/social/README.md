# Áudio social do Rota da Justiça

A cena de bar procura, opcionalmente, o arquivo:

`/audio/social/bar-ambience.mp3`

O jogo continua funcionando normalmente se esse arquivo não existir: os efeitos visuais permanecem ativos e a interface avisa que o áudio opcional ainda não foi instalado.

Use somente áudio próprio, licenciado ou royalty-free com licença compatível com a distribuição do jogo. O arquivo não foi incluído automaticamente no repositório para evitar incorporar mídia sem licença adequada.

Recomendação para o asset final:
- loop ambiente de bar com conversa distante, copos e música de fundo;
- duração entre 30 e 90 segundos, preparado para loop;
- volume normalizado sem picos agressivos;
- formato MP3 para compatibilidade ampla.
